# 3D Portfolio Website

This project is a 3D portfolio website developed with Three.js and React. It features interactive 3D models and animations to create an engaging user experience. The portfolio is divided into sections showcasing projects, skills, and contact information, all within a dynamic 3D environment.

## Features

- **Interactive 3D Models**: Explore various 3D models that respond to user interactions.
- **Animations**: Smooth animations enhance the visual appeal and user experience.
- **Project Showcase**: Highlight your projects with detailed descriptions and visuals.
- **Skills Section**: Display your skills and expertise in a visually appealing manner.
- **Contact Information**: Easy access to contact details within the 3D space.

## Objective

The primary objective of this project is to highlight expertise in Three.js, React, and web development, while providing an immersive platform to present personal work and achievements.

## Technologies Used

- **Three.js**: For creating and rendering 3D graphics.
- **React**: For adding interactivity and animations.
- **HTML/CSS**: For structuring and styling the website.
